# Vela v0.2.1

For Apple Silicon Macs running macOS 13 or later.

## Features and improvements

- Save custom routing rules independently for each subscription, with exact-domain and domain-suffix matching and direct, block, or existing proxy-group targets. Rules persist across subscription updates.
- Cancel subscription downloads and latency tests. The interface stays responsive during connection startup, and quitting cancels any startup in progress.
- Preserve valid proxy selections and the active subscription across updates, and import configurations while connected.
- Edit subscription URLs in a dialog, confirm deletion within the app, and remove associated configuration files when deleting subscriptions.
- Pause interface polling while the window is hidden and refresh immediately when it reappears. Large rule lists use virtual scrolling.
- Refine the home layout, routing controls, scrollbars, and navigation icons, and introduce a sailboat menu bar icon.

## Fixes and security updates

- Prevent the core state lock from blocking controller reads and clarify startup error messages.
- Fix stale rule-list container heights after refreshing data in WebKit.
- Update source-map-js, use Go 1.26.9, and update the bundled mihomo core's dependencies for security fixes, including x/net v0.60.0.
- Bundle Mihomo v1.19.31-vela.2.

## Download and verification

Release assets:

- `Vela-v0.2.1-macos-arm64.dmg`
- `Vela-v0.2.1-macos-arm64.dmg.sha256`

Run this command in the download directory:

```sh
shasum -a 256 -c Vela-v0.2.1-macos-arm64.dmg.sha256
```

Open the DMG and drag Vela into Applications.
This build is ad-hoc signed. It is not signed with an Apple Developer ID or notarized by Apple.
