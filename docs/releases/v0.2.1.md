# Vela v0.2.1

适用于 macOS 13 及以上版本的 Apple Silicon Mac。

## 新增与改进

- 按订阅独立保存自定义路由规则，支持域名、域名后缀、直连、阻断及现有策略组；订阅更新后保留规则。
- 订阅下载与节点测速支持取消，连接启动保持响应，退出时可取消未完成的启动。
- 订阅更新后保留有效的节点选择和当前订阅；支持在连接期间导入配置。
- 订阅地址改为弹窗编辑，删除操作使用应用内确认，并清理关联配置。
- 窗口隐藏时暂停界面轮询，恢复显示时立即刷新；大规则列表使用虚拟滚动。
- 调整首页布局、路由控件、滚动条与导航图标，菜单栏采用帆船图标。

## 修复与安全更新

- 修复内核状态锁阻塞控制器读取，以及启动错误提示不清晰的问题。
- 修复 WebKit 中规则列表刷新后容器高度未正确更新的问题。
- 更新 source-map-js、Go 1.26.9 与 mihomo 的安全维护依赖，包括 x/net v0.60.0。
- 内置内核为 Mihomo v1.19.31-vela.2。

## 下载与校验

发布附件：

- `Vela-v0.2.1-macos-arm64.dmg`
- `Vela-v0.2.1-macos-arm64.dmg.sha256`

在下载目录执行：

```sh
shasum -a 256 -c Vela-v0.2.1-macos-arm64.dmg.sha256
```

打开 DMG 后，将 Vela 拖入 Applications。
本构建使用 ad-hoc 签名，未使用 Apple Developer ID 签名或公证。
